# 世外桃源 · 微观山水

可交互的三维微缩山水：四季、日夜、云雨、风、溪瀑与池塘，以及树木、山居、游鱼和飞鸟。

**[在线试玩](https://1364479497-crypto.github.io/microcosm-landscape/)**

当前版本 **2.3.10**，使用本地随站提供的 **Three.js 0.187.0 / r187**。无需 API 密钥或后端服务。

## 操作

- 拖动空白处旋转，滚轮或双指缩放；拖动太阳/月亮改变时间。
- 左侧切换季节与时间，右侧选择天气和互动工具。
- 抓住云层可产生局部降雨，点击池水可激起涟漪。
- 顶栏可选择自动、清晰、流畅或录制画质，并控制声音、截图和复位。

首次加载需要生成景观。录屏时可选择顶栏「录制」，或在地址后加 `?render=record`。录制档限制输出尺寸和最高帧率，并降低远处植被和渲染通道的开销。实际帧率取决于设备和录制负载。环境声音可能需要首次点击后才能播放。桌面 Chrome/Metal 已完成本轮检查，其他设备和浏览器的表现仍需实际验证。

## 本地运行

在仓库目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8080/`。本仓库已包含运行所需的库与素材，无需 npm 安装或构建。`runtime-manifest.json` 记录实际运行文件的 SHA-256。
